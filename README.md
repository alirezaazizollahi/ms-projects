# EmbarkX Microservices

This repository is a collection of independent Spring Boot Maven applications
for an ecommerce example. It includes Eureka discovery, centralized
configuration, and user, product, and order services. Each application has its
own Maven wrapper; there is no root Maven aggregator.

See [the project guide](docs/ai-docs/README.md) for the architecture, service
inventory, configuration, startup guidance, and current known issues. Repository
contributor guidance is in [AGENTS.md](AGENTS.md).
